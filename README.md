SimplyChat is a real-time chat application built with JavaScript and powered by Supabase. It features dynamic chat rooms, GitHub authentication, and a clean, minimalist interface.

Link: [https://sclf-xingshu.github.io/SimplyChat/ ↗️](https://sclf-xingshu.github.io/SimplyChat/)

---

## Features

- Real-time messaging
- GitHub login
- Customizable chat rooms - search, explore trending/popular rooms
- Font size controls
- Animated particle background
- Mobile-responsive design
- Green [GH] user tag for GitHub-authenticated users

---

## Built With

- HTML / CSS
- JavaScript
- Supabase
- DOMPurify
- GitHub Pages
- Self-hosted Google Fonts (Cal Sans and Inter)
