[Feature] Guide to the custom link syntax

June 23, 2026

You can now link to chatrooms, users, messages and pages directly from your messages! Here's how it works:

You type It links to
\@/global\ Chatroom /global
\@/global;msg:12345\ Message #12345 in /global
\@SCLF-Xingshu\ User profile
\@msg:12345\ Message #12345 in current chatroom
\~home\ Home page
\~blog\ Blog page
\~explore\ Explore page
\https://example.com\ External website

Note: The syntax only allows HTTPS URLs (eg. https://example.com). It does not allow HTTP URLs (eg. http://example.com) for safety reasons.

Just type any of these in your message - they will automatically become clickable links! Give it a try 😊
